# spotify-cli

Control Spotify from the terminal. Play, pause, skip, search and queue tracks
without switching windows.

> **Status:** early development. Not usable yet.

## Requirements

- Spotify Premium (the Spotify Web API allows playback control only for Premium accounts)

## Planned commands

    spotify play
    spotify pause
    spotify next
    spotify now
    spotify search "bohemian rhapsody"
    spotify queue "paranoid android"
